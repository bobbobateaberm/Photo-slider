# 📸 React Photo Slider & Image Manipulator

A dynamic React application built with **Vite**, **Tailwind CSS**,  to showcase advanced state management, interactive hooks, and dynamic image transformation. This project delivers a fluid, desktop-optimized photo slider featuring randomization, layout switching, styling manipulation, and live filtering.

## Features

### 1. Advanced State Management & Custom Hooks
### 2. Image Randomization & Sourcing
### 3. Comprehensive Manipulation Studio
### 4. Layout & UI Adaptability
---

## Tech Stack & Architecture

* **Core:** React 18+ (Functional Components)
* **Styling:** Tailwind CSS (Utility-first styling, arbitrary values, smooth transition states)
